# Jira Analyze

Приложение на PyQt6 для визуализации публичных данных Apache Jira.

Первая кнопка строит гистограмму времени жизни закрытых задач от `created` до
`resolutiondate`.

Вторая кнопка восстанавливает историю переходов по `changelog` и строит
отдельную гистограмму времени для каждого состояния закрытых задач.

Третья кнопка загружает задачи проекта `KAFKA` за последние 20 календарных
дней и показывает:

- количество заведённых задач за каждый день;
- количество закрытых задач за каждый день;
- накопительный итог заведённых задач;
- накопительный итог закрытых задач.

Закрытые задачи определяются по полю Jira `resolutiondate`. Накопительный итог
считается внутри отображаемого двадцатидневного периода.

Четвёртая кнопка строит горизонтальную составную диаграмму для 30 пользователей
с наибольшим суммарным количеством ролей в задачах проекта `KAFKA`. Синяя
часть полосы показывает задачи, где пользователь указан исполнителем, оранжевая
— задачи, где он указан репортёром. Число справа показывает их сумму.

Пятая кнопка анализирует только закрытые задачи с заполненным worklog. Слева
показывается гистограмма количества задач по интервалам залогированного времени,
справа — до 30 пользователей с максимальным суммарным временем в worklog.
Если пользователей с worklog меньше 30, отображаются все доступные пользователи.

Шестая кнопка строит столбчатый график количества всех задач проекта KAFKA
по степени серьёзности из стандартного поля Jira `priority`.

## Запуск

```bash
poetry install
poetry run python main.py
```

Для загрузки статистики приложению нужен доступ к
`https://issues.apache.org/jira`.

## Структура проекта

- `main.py` — главное окно и отрисовка графиков;
- `statistics_loader.py` — фоновая загрузка данных;
- `jira_api.py` — клиент публичного Jira REST API;
- `jira_api_error.py` — ошибка клиента Jira;
- `models/` — отдельные модели данных для каждого графика.
